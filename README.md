# 모비 커넥터 리모콘

마비노기 모바일 PC 클라이언트(1920x1080)를 대신 돌려 주는 리모콘. 일일·주간 숙제, 어비스·레이드 반복, 제작·가공·채집 목표를
작업 큐에 카드로 쌓아 위에서부터 하나씩 돌린다. 게임 상태는 공식 AI 커넥터 CLI 와 받기 전용 패킷 감시로 읽고,
게임 조작은 화면 인식(그림 맞추기·OCR) + 키·마우스 입력으로 한다.

> 넥슨 운영정책상 매크로 사용은 제재 대상이 될 수 있습니다. 사용 책임은 본인에게 있습니다.

## 할 수 있는 일

| 탭 | 내용 |
|---|---|
| 캐릭터 | 숙제할 캐릭터(슬롯)와 캐릭터별 숙제 설정. 캐릭터 선택 화면을 읽어 자동으로 채우기 |
| 숙제 | 일일 숙제(요일 던전·은동전·공물·검은 구멍·일일 미션·아르바이트), 주간 숙제(필드 보스·뱅가드 브리치·주말 어비스·레이드), 기타(나이트메어 드릴·각인 강화 반복) |
| 어비스·레이드 | 반복 — 판 수·시간 제한, 게임을 뒤로 보내고 돌기, 판 사이 장비 수리, 궁극기·팔라딘 변신 (어디서나 · 보스에서만) |
| 제작·가공·채집 | 목표 수량까지 재료를 거슬러 계산해 한 걸음씩, 가공 시설 칸 관리 |
| 대시보드·소지품·미션 | 캐릭터·재화·주변, 가방·보관함, 일일·주간 미션 조회 |
| 연주·소셜 | 악보 재생목록, 채팅·표정·행동 |
| 염색 | 염색 팔레트에서 목표 색 자리를 찾아 게임 위에 겹쳐 보여 줌 |

- **작업 큐**: 모든 일은 카드로 줄을 선다. 끝나면 결과 창(한 일·얻은 것), 게임 구석에 진행 오버레이.
- **혼자 버티기**: 연속 실행 제한 창이 뜨면 게임을 다시 켜서 같은 캐릭터로 이어 하고, 서버 연결이 끊기면(점검) 게임을 끄고 일시정지한다.
- **명령 통로**: 다른 프로그램이 파이프 `MobiRemote-control` 로 상태를 묻고 카드를 넣는다 (`gui_app/control.py`, 명령 목록은 `hello`).

## 설치

- [릴리스](https://github.com/Oxtakarnus/mobi-remote/releases)의 `mobi-remote-<판>-setup.exe`. 새 판은 켤 때 확인하고, 옵션 창
  '새 판 확인' 에서 받아 설치한다 (런타임 구성이 같으면 작은 패치 zip 만 받는다).
- 게임 설정의 **MM AI 에이전트 활성화**를 켠다. 게임 상태 조회와 제작·가공·채집 명령에 쓴다.
- **[Npcap](https://npcap.com/#download)** (무료)을 함께 깔면 좋다. 게임 서버가 보내는 패킷을 받기만 해서 맵 이동·던전·대화·결과를
  화면보다 빨리 안다. 무료판은 재배포가 허락되지 않아 설치 파일에 넣지 않는다. 없으면 켤 때 알림 띠와 옵션 창 '패킷 감시' 줄에서
  받는 곳을 열고, 설치한 뒤 '다시 확인' 을 누르면 다시 켜지 않고 감시가 켜진다. 없어도 리모콘은 CLI·화면으로 돈다.
- 게임이 관리자 권한으로 돌아서 리모콘도 관리자 권한으로 뜬다 (아니면 UAC 로 다시 띄운다). 관리자가 아니면 입력이 무시된다.
- 게임을 앞에 두고 하는 일은 화면을 캡처해서 보므로 다른 창으로 가리지 말고, Windows **방해 금지 모드**를 켜 둔다.

## 단축키

**F12** = 일시정지 · 다시 누르면 이어 하기, **Shift+F12** = 지금 카드만 중단하고 다음 카드로, **Ctrl+F12** = 큐 전체 중단.
일시정지 키는 옵션 창 '리모콘 단축키' 에서 바꾼다. 게임 조작키 설정에서 바꾼 키는 '게임 단축키' 가 저절로 따라간다 (옵션에서 따로 정한 키가 앞선다).

## 캐릭터 슬롯

캐릭터 선택 화면에서 왼쪽 위부터 1, 2, 3, 4 / 다음 줄 5, 6 … 순서로 번호를 매긴다.
- 선택 화면 정렬은 **캐릭터 생성 순**으로 둔다. 정렬이 바뀌면 번호가 달라진다.
- 카드 위치는 카드의 `•••` 버튼으로 계산하고, 스크롤과 노란 선택 테두리를 확인한 뒤에만 접속한다. 확인에 실패하면 엉뚱한 캐릭터로
  들어가지 않고 실패로 끝낸다.
- 캐릭터 접속 사이에는 `[login] min_interval` 초 이상 둔다 (잦은 전환은 인증 오류를 부른다).

## 기록

옵션 창 '폴더' 에서 연다.
- `logs/<날짜>.log` 실행 로그, `logs/shots/` 실패·확인용 스크린샷 (7일 지나면 지운다), `logs/acts/<날짜>.jsonl` 상황 판단 기록
- `queue-history.jsonl` 큐 카드마다 결과 (화면의 '작업 기록')
- `state/<게임 날짜>.json` 하루 숙제 진행 — 게임은 **오전 6시**에 초기화되므로 6시 전은 전날로 친다. 끊기면 그 자리부터 이어 한다.

## 개발

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\pip install --no-deps rapidocr   # 한글 OCR (의존성을 같이 깔면 opencv-python-headless 가 겹친다)
.\.venv\Scripts\pythonw.exe gui.py               # 화면
```

- 소스로 띄우면 관리자 확인 창·작업 표시줄에 'Python' 으로 뜬다. `.venv\Scripts\python.exe tools\make_launcher.py --shortcut <바로가기.lnk>`
  로 시작 프로그램(`.venv\Scripts\모비 커넥터 리모콘.exe`, Windows 기본 .NET 컴파일러로 만든다)을 만들고 바로가기를 그쪽으로 돌린다.
  리모콘의 다시 시작도 이 exe 가 있으면 그것으로 띄운다.

- 켜진 리모콘에 명령 보내기: `gui.py --halt` · `--resume` · `--enhance` · `--restart-game` · `--abyss 슬롯 던전 [판수] [난이도] [solo|party]` · `--raid …`
- 콘솔 실행 (일일 숙제만): `run.py` — `--chars 5,6` 일부 슬롯, `--only silver` 일부 숙제, `--current` 지금 캐릭터로, `--force` 끝낸 숙제도,
  `--dry-run` 클릭 없이 인식만, `--list` 숙제 id, `--setup` 슬롯 다시 입력
- 시험: `.\.venv\Scripts\python.exe -m unittest discover -s tests`, 웹 `node tests\queue.test.js` · `node tests\web_load.test.js`
- 배포판: `.\.venv\Scripts\python.exe tools\build.py` → `dist\mobi-remote-<판>-setup.exe` + 패치 zip
- 템플릿 만들기: `tools\capture.py missing` (필요한 목록) → `snap` (게임에서 F9 로 찍기, F10 끝) → `crop <파일> <이름>` →
  `test <이름>` (0.85 이상이면 양호). 버튼의 변하지 않는 부분(아이콘·글자)만 작게 자른다.

설정은 `config.default.toml` 이 기본값이고, 사용자 `config.toml` 에는 이와 다른 값만 저장된다 (새 판에서 바뀐 기본값이 그대로 적용된다).
